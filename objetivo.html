¡Objetivo!

El objetivo principal de esta práctica es diseñar y desarrollar un sitio web estático estructurado, aplicando principios de maquetación (layout) mediante el uso de etiquetas HTML (div, span) para organizar el contenido en secciones bien definidas. El propósito central es lograr una presentación visual uniforme y profesional en múltiples páginas a través de la investigación e implementación del framework Bootstrap, combinado con hojas de estilo CSS externas.

A través de este proyecto, se busca poner en práctica la correcta separación entre la estructura del documento y su diseño visual, garantizando una navegación funcional.

Los propósitos técnicos y prácticos específicos incluyen:

  • Implementar un layout estándar.
  • Integrar CSS y Bootstrap.
  • Construir un sitio navegable.
  • Utilizar correctamente el código HTML para dar formato al texto, incluyendo párrafos, múltiples niveles de encabezados, listas anidadas (ordenadas y no ordenadas), tablas, citas y énfasis (negritas/cursivas).
