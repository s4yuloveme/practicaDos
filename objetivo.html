¡Objetivo!

El objetivo principal de esta práctica es diseñar y desarrollar un sitio web estático estructurado, aplicando principios de maquetación (layout) mediante el uso de etiquetas HTML para organizar el contenido en secciones bien definidas. El propósito central es lograr una presentación visual uniforme y profesional en múltiples páginas a través de la investigación e implementación del framework Bootstrap, combinado con hojas de estilo CSS externas.

A través de este proyecto, se busca poner en práctica la correcta separación entre la estructura del documento y su diseño visual, garantizando una navegación funcional.

Propósitos técnicos específicos:

  • Implementar un layout estándar.
  • Integrar tecnologías de diseño:
    • Uso del framework Bootstrap 5.
    • Hoja de estilos externa (style.css).
  • Utilizar correctamente las etiquetas HTML para dar formato al texto (negritas y cursivas).

Fases de Desarrollo de la Práctica:

  1. Fase de Planeación y Diseño
    1. Definir la paleta de colores y el estilo visual general.
    2. Estructurar el layout base (Header, Sidebar, Content, Footer).
  2. Fase de Codificación
    1. Crear los 5 archivos HTML requeridos.
    2. Enlazar la barra de navegación para que sea funcional en todas las páginas.

Estructura de Archivos del Proyecto

Archivo Descripción
principal.html Página principal de presentación de la práctica.
objetivo.html Expresa los propósitos técnicos y aprendizajes de la práctica.
sitiopersona.html Página personal con la información actualizada de los integrantes.
mapadelsitio.html Mapa funcional con hipervínculos para la navegación rápida.
style.css Hoja de estilos que le da el formato visual a los paneles y tablas.
